<h1>File Upload Attacks - FOR EDUCATIONAL PURPOSES ONLY</h1>

A file upload attack occurs when an attacker exploits a web application's file upload feature to upload malicious files, potentially leading to remote code execution, data theft, or server compromise.

Impact: Code Execution, Information Disclosure, Availability Impact (Potential Denial Of Service)
